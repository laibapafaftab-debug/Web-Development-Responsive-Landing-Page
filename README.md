# Focal — Responsive Landing Page

Inovegen Internship Program 2026 — Week 1, Task 1 (Web Development, Front-End Track)

## About

A responsive landing page for **Focal**, a fictional focus-timer and deep-work tracking app. Built from scratch using semantic HTML5 and modern CSS3 — no frameworks or templates.

## Tech Stack

- HTML5 (semantic markup: `header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 (Grid, Flexbox, custom properties, media queries)
- Vanilla JavaScript (dark/light mode toggle, scroll-reveal animations)
- Google Fonts (Fraunces + Inter)

## Features

- Fully responsive layout (mobile, tablet, desktop breakpoints)
- Hero section with headline, description, and CTA
- 3 feature highlights, testimonials section, and footer
- Dark/light mode toggle with saved preference
- CSS transitions and scroll-triggered entrance animations
- SEO metadata, Open Graph tags, and a custom favicon

## How to View

Open `index.html` in any browser — no build step or dependencies required.
