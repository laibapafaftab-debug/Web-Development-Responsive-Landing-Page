
# Focal — Responsive Landing Page

Inovegen Internship Program 2026 — Week 1, Task 1 (Web Development, Front-End Track)

**Live demo:** https://laibapafaftab-debug.github.io/Web-Development-Responsive-Landing-Page/

## About

A responsive landing page for **Focal**, a fictional focus-timer and deep-work tracking app. Built from scratch using semantic HTML5 and modern CSS3, with no frameworks or templates.

## Tech Stack

- HTML5 (semantic markup: `header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 (Grid, Flexbox, custom properties, media queries)
- Vanilla JavaScript (dark/light mode toggle, scroll-reveal animations)
- Google Fonts (Fraunces + Inter)

## Features

- Responsive layout with mobile, tablet, and desktop breakpoints
- Hero section with headline, description, two calls to action, and a CSS-built timer card illustration
- Trust strip, three feature cards, three testimonials, and a closing call to action
- Dark/light mode toggle; the choice is saved in `localStorage` and applied before the page paints
- Hero entrance animation on load and scroll-triggered reveal with staggered cards
- Hover and transition effects on navigation links, buttons, and cards
- Respects `prefers-reduced-motion`; content stays visible if JavaScript is disabled
- SEO metadata, Open Graph tags, and a custom favicon
